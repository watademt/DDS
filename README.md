# 💰 Учет движения денежных средств (Cash Flow Tracker)

Этот репозиторий содержит веб-сервис для учета и контроля движения денежных средств (ДДС). 

Проект представляет собой инструмент для фиксации финансовых операций. В его основе лежит строгая иерархическая система справочников (Статус ➔ Тип ➔ Категория ➔ Подкатегория), которая гарантирует целостность данных. Интерфейс позволяет удобно добавлять новые записи (с динамической подгрузкой категорий без перезагрузки страницы) и фильтровать историю транзакций по множеству параметров.

## 🛠 Стек технологий

Проект разработан с использованием классического монолитного подхода с элементами AJAX для улучшения пользовательского опыта:

* **Backend:** Python, Django 5.
* **API & Фильтрация:** Django REST Framework (для эндпоинтов фронтенда), `django-filter`.
* **База данных:** SQLite (идеально для локального развертывания).
* **Frontend:** HTML5, CSS (фреймворк Bootstrap 5 через CDN).
* **Интерактивность:** Vanilla JavaScript (Fetch API для работы динамических выпадающих списков).

## 🚀 Инструкция по локальному запуску

Ниже описаны шаги для быстрого запуска проекта на вашем компьютере. Убедитесь, что у вас установлен **Python версии 3.10** или выше, а также система контроля версий **Git**.

### Шаг 1. Клонирование репозитория
Откройте терминал, перейдите в директорию, где хотите разместить проект, и выполните команду:
```bash
git clone <вставьте-ссылку-на-ваш-репозиторий>
cd dds_project
```

### Шаг 2. Настройка виртуального окружения
Создайте изолированное виртуальное окружение командой:
```bash
python -m venv venv
```

После создания окружение необходимо активировать:
* **Для Windows (PowerShell/CMD):**
  ```bash
  venv\Scripts\activate
  ```
* **Для Linux / macOS:**
  ```bash
  source venv/bin/activate
  ```

### Шаг 3. Установка зависимостей
Установите все необходимые библиотеки, перечисленные в файле конфигурации:
```bash
pip install -r requirements.txt
```

### Шаг 4. Настройка базы данных
Создайте структуру таблиц в базе данных SQLite, выполнив команду миграций:
```bash
python manage.py migrate
```

### Шаг 5. Создание администратора (Обязательно!)
Бизнес-логика приложения завязана на справочники (Статусы, Типы, Категории). Прежде чем создавать транзакции, **справочники необходимо наполнить через панель администратора**. 

Создайте учетную запись суперпользователя:
```bash
python manage.py createsuperuser
```
*Система попросит вас придумать Username (логин), Email (можно пропустить) и Password (пароль при вводе скрыт).*

### Шаг 6. Запуск веб-сервиса
Теперь всё готово к запуску локального сервера разработки:
```bash
python manage.py runserver
```

Проект будет доступен в браузере по адресу: **http://127.0.0.1:8000/**

> **💡 Быстрый старт после запуска:**
> 1. Перейдите по адресу `http://127.0.0.1:8000/admin/` и авторизуйтесь.
> 2. Добавьте базовые данные в таблицы **Статусы** (например: Личное, Бизнес) и **Типы** (Пополнение, Списание).
> 3. Добавьте **Категории** (привязав их к Типам) и **Подкатегории** (привязав их к Категориям).
> 4. Вернитесь на главную страницу сервиса `http://127.0.0.1:8000/` и нажмите "Новая запись" — выпадающие списки будут работать корректно!
